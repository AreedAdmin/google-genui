# Open Questions & Decisions Log

> Status: **Living document.** The single registry of unresolved decisions and risks for Trellis. Each row has an ID, the question, the options, a current lean/recommendation, a priority, and a status. This is the only doc that is *expected* to change continuously; everything else is canonical against it. The program-level definition of done requires **no open P0 rows** (`../00-overview/deliverables.md`).

## How to use this doc

- **Priority:** `P0` = blocks the definition of done / a core guarantee; `P1` = needed before customer-facing (phase B, `../00-overview/scope.md` §6); `P2` = important but deferrable.
- **Status:** `open` (undecided) · `leaning` (lean recorded, not committed) · `decided` (resolved — fold the decision into the relevant canonical doc and keep the row as a record) · `deferred`.
- When a row is **decided**, update the owning canonical doc and flip status to `decided` here; do not delete the row (it's the decision log).
- New questions get the next `OQ-NN` id; never reuse ids.
